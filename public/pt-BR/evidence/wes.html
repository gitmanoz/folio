## 7b. Composition patterns (Fatia C)

Vocabulário fechado de composição materializada pelo Generator (além de density/highlight/motion):

| `compositionPattern` | Materialização |
|---|---|
| `stacked-default` | Seção empilhada (baseline) |
| `banner-hero-split` | Hero split atmospheric |
| `banner-carousel` | Carousel de banners (`bullet` ou path em `body`) |
| `asymmetric-blocks` | Mosaic tipográfico de spans |
| `narrative-chain` | Lead + cadeia de bullets |
| `timeline-horizontal` | Nós + painel sob demanda |
| `statement-orbit` | Declaração tipográfica |
| `weighted-blocks` | Blocos com peso tipográfico |
